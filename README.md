# David Blitz Portfolio

Initial Next.js portfolio scaffold for David Blitz, University of Waterloo Computer Engineering.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown by Next.js.

## Deploy

Push this repository to GitHub, then import it into Vercel. No environment variables are required for the first version.
